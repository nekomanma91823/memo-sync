# メモシンク

すぐ書ける、日本語のシンプルなメモの Chrome 拡張機能です。番号のタブでメモを切り替え、複数の PC に同期できます。

Chrome ウェブストアでの公開を準備しています。今はソースから読み込んで使えます。手順は [開発の手引き](docs/development.md) にあります。

## できること

- **書く**：番号のタブでメモを切り替えます。書いたそばから保存します。日時や、表示中のページのタイトルと URL をボタンで入れられます。右クリックで、選んだ文字をメモに送れます。サイドパネルでも開けます。
- **Markdown**：書式を付けて表示に切り替えると、見出しや表が整って見えます。チェックボックスは押すだけで入れ替わります。「書式付きでコピー」で、Slack・Google ドキュメント・Gmail に貼っても書式が残ります。
- **探す・置換**：すべてのメモから探して、置換できます。大文字と小文字、全角と半角、ひらがなとカタカナは区別しません。置換の直後は「元に戻す」で戻せます。
- **画像**：貼り付けとドラッグで画像を足せます。四角・矢印・文字で印を付けられます。書いている場所に `[画像 1]` の印が入ります。
- **AI に渡す**：「コピー」で、文章と画像の保存場所をまとめてコピーします。Claude Code などのコーディング AI にそのまま貼れます。
- **整理**：グループで絞り込めます。メモのタブもグループも、ドラッグで並べ替えられます。削除したメモと画像は、ゴミ箱から 30 日間戻せます。テキストや ZIP で書き出し・取り込みができます。
- **守る**：パスワード・API キー・個人情報らしい文字を見つけて知らせます。コピーの前に、見つけた文字を伏せられます。メモを隠して、画面に出さないこともできます。隠すのは画面だけで、暗号化はしません。

## キー操作

| 操作 | Windows など | Mac |
|---|---|---|
| メモを開く | Alt+Shift+M | Control+Shift+M |
| すべてのメモから探す | Ctrl+F | ⌘F |
| 置換する | Ctrl+H | ⌘⇧H |
| 書式を付けて表示する | Ctrl+E | ⌘E |
| タブを並べ替える | Alt+← と Alt+→ | Option+← と Option+→ |
| グループを並べ替える | Alt+← と Alt+→ | Option+← と Option+→ |

メモを開くキーは、設定画面から変えられます。

## 同期の方式

設定画面で、次の 2 つから選びます。すべての PC で同じ方式を選んでください。

| 方式 | 準備 | 容量 | 画像 |
|---|---|---|---|
| Chrome の同期機能 | 各 PC で Chrome にログインし、同期をオンにする | 合計 100KB。日本語でおよそ 3 万字 | 貼れない |
| Google ドライブ | 設定画面で Google アカウントにログインする | 気にしなくてよい | 貼れる |

Google ドライブでは、ドライブの中の、このアプリ専用の見えない場所に保存します。ほかのファイルは読みません。

## データの扱い

- メモは、利用者の PC と、利用者の Google アカウントの中だけに置きます。開発者のサーバーはありません。
- 利用状況の記録や広告はありません。
- 要注意の文字を調べるのは、PC の中だけです。
- 書式を付けて表示するとき、外のサイトの画像は読み込みません。
- 外部のライブラリやスクリプトは使っていません。

詳しくは [プライバシーポリシー](docs/privacy-policy.md) を見てください。
