# 用語集

画面の文を書くときは、この表の「使う語」を使います。同じものを別の語で呼ばないためです。

| 使う語 | 使わない語 | 使う場面 |
| --- | --- | --- |
| 削除 | ゴミ箱に移す | メモや画像をゴミ箱に入れる操作。ボタンとお知らせは「削除」と言い、戻し方は「ゴミ箱から 30 日間戻せます」と添える |
| 消す | 削除 | ゴミ箱から消して、もう戻せなくなる操作だけに使う |
| やめる | キャンセル、いいえ | 確認や欄を閉じて、何もしないボタン。このアプリの決めごと |
| タイトル | 題、題名 | ページのタイトル。「URL を入れる」と右クリックの送信で入れるもの |
| ドラッグ | 落とす | タブやファイルを持っていって離す操作 |
| 隠す | 非表示、ロック | メモの中身を画面に出さないこと。暗号化ではない |
| グループ | フォルダ、タグ | タブの上の行で絞り込むまとまり |
| 取り込み・書き出し | インポート・エクスポート | ファイルからメモを入れる操作と、ファイルに出す操作 |
| 書式付きでコピー | リッチテキストでコピー、HTML でコピー | Markdown を書式にして、Slack やメールに貼れる形でコピーする操作 |
| 記号を外してコピー | プレーンテキストでコピー | # や ** を外した文字だけをコピーする操作 |
| 書式を付けて表示 | プレビュー、レンダリング | Markdown を整えた見た目でメモを見せること。戻すときは「編集」 |
| 置換 | 置き換え、リプレース | 見つけた文字を別の文字に変える操作。ボタンは「置換」「1 件置換」「すべて置換」、欄は「置換後の文字」 |

## 文の決まり

- 画面の文は括弧で補足しません。補足は文を分けて書きます。
- ボタンは押した結果を動詞で書きます。例：「削除する」「表示する」。
- プレースホルダーは「例：仕事」の形にし、説明はほかの場所に書きます。
- 省略記号は「…」を使います。
