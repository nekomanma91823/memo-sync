## 1. 取り扱う情報

メモシンクを、以下「本拡張機能」と呼びます。本拡張機能が扱うのは、利用者が本拡張機能に入力したメモの本文、メモに付けた名前・グループ・「隠す」の印、メモに貼り付けた画像、本拡張機能の設定だけです。
次の操作をしたときに限り、表示中のページの情報を読み取ってメモに書き入れます。

- 「URL を入れる」ボタン：表示中のページのタイトルと URL
- 右クリックの「選んだ文字をメモシンクに送る」：選んだ文字と、そのページのタイトルと URL

## 2. 保存する場所

メモと設定は、次の場所にだけ保存します。

- 利用者の PC の中にある、Chrome の拡張機能用の保存領域
- 利用者が「Chrome の同期機能」を選んだ場合：利用者の Google アカウントの Chrome 同期データ
- 利用者が「Google ドライブ」を選んだ場合：利用者の Google ドライブの、本拡張機能専用のフォルダ appDataFolder

画像を貼り付けられるのは「Google ドライブ」を選んだ場合だけです。画像は、利用者の PC の中と、上の専用フォルダにだけ保存します。
また、利用者が画像の付いたメモを「コピー」したときは、その画像を利用者の PC の「ダウンロード」フォルダの中の memosync フォルダに、ファイルとして保存します。
削除したメモと画像は、利用者の PC の中のゴミ箱に 30 日間残します。グループの色と並び順は、利用者の Google アカウントの Chrome 同期データに保存します。
メモの名前・グループ・「隠す」の印は、メモの本文と同じ場所に保存し、同じように同期します。テーマ・色・大きさなどの見た目の設定は、利用者の PC の中にだけ保存します。

本拡張機能は、メモの本文にパスワード・API キー・個人情報らしい文字がないかを、利用者の PC の中だけで調べます。メモの画面に印を出し、「コピー」の前に伏せるかを聞くためです。
調べた結果は画面に出すだけで、保存も送信もしません。「このメモを隠しますか」に答えたメモの記録だけを、利用者の PC の中に残します。

提供者のサーバーにメモや設定を送ることはありません。提供者がメモの内容を見ることもできません。

## 3. Google のデータの利用

Google ドライブ同期では、Google の `https://www.googleapis.com/auth/drive.appdata` の権限だけを使います。
この権限では、本拡張機能が作ったメモと画像のファイルだけを読み書きでき、利用者のほかのファイルは読めません。
設定画面に使用量を出すため、利用者の Google アカウントの容量の、使用量と上限も読み取ります。読み取った値は画面に出すだけで、保存も送信もしません。

本拡張機能が Google API から受け取った情報の使用と、他のアプリへの転送は、
[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)
に、「限定使用」の要件も含めて従います。

## 4. 第三者への提供・計測

- メモや設定を第三者に提供・販売することはありません。
- アクセス解析などの利用状況の計測や、広告は入れていません。
- 外部のスクリプトを読み込むことはありません。

## 5. 削除

- 本拡張機能を削除すると、PC の中の保存データは Chrome によって消去されます。
- Google ドライブ同期の接続は、設定画面の「接続を解除する」で取り消せます。Google アカウントの
  「サードパーティのアプリとサービス」からも取り消せます。
